# OmniBot On The Move

OmniBot On The Move is a small Python toolchain for planning and executing omnidirectional robot trajectories. It combines a Tkinter-based obstacle editor, a trajectory request client, and a TCP control loop that streams wheel speeds to the robot.

### What it does

- Draw obstacles, start, and finish points in a GUI.
- Send the scene to the trajectory server.
- Download the computed trajectory and store it in `traj.json`.
- Run the control loop that reads the trajectory and sends motor commands over TCP.

### Project Layout

- `main.py`: entry point that configures the trajectory server, opens the GUI and starts robot-thread.
- `gui.py`: obstacle editor and start/stop controls.
- `client.py`: HTTP helpers for obstacle and trajectory requests.
- `omnibot.py`: robot control loop and wheel-speed mapping.
- `tcp.py`: low-level TCP connection wrapper.
- `shared.py`: obstacle data classes.
- `traj.json`: trajectory generated by the server.

### Requirements

- Python 3
- `tkinter`
- `requests`

### Setup

Check if dependencies are satisfied:

```bash
make check-deps
```

#### If dependencies are not satisfies.

Install the Python dependency with:

```bash
pip install requests
```

If your Python installation does not include Tk support, install or switch to a Python build that does.

### Running

The default entry point is `main.py`:

```bash
python3 main.py
```

There is also a Makefile target:

```bash
make run
```

The Makefile checks that `tkinter` and `requests` are available before launching the app.

### How the application works

1. Start the app from `main.py`.
2. Create or edit obstacles in the GUI.
3. Place the start and finish points.
4. Click `Send to server` to post the scene and generate a trajectory.
5. Click `Start` to begin the control loop.
6. Click `Stop` to pause the bot.

### GUI Controls

- `Select / Move`: select an obstacle and drag it.
- `Circle`, `Box`, `Triangle`: place a new obstacle of that type.
- `Place Start`, `Place Finish`: set the trajectory endpoints.
- `Delete Selected`: remove the active obstacle.
- `Send to server`: upload the current scene and generate `traj.json`.
- `Start` / `Stop`: control the robot execution loop.

### Configuration

The network endpoints are set in `main.py` and `client.py`:

- `HOST`: robot TCP host
- `PORT`: robot TCP port
- `SERVER_URL` / `BASE_URL`: trajectory server address

Update those values to connect to the correct robot.

### Notes

- `traj.json` is overwritten each time a new trajectory is generated.
- The GUI only allows one send operation per app session to avoid accidental resubmission.
- The control loop expects the trajectory arrays in `traj.json` to be present before `Start` is used.
